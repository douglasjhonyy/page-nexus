# NEXUS — Landing Page

Landing page desenvolvida do zero a partir de uma estrutura de design criada no Figma.

O projeto apresenta uma interface inspirada em um universo de ficção científica, com seção de apresentação, personagens e conteúdo relacionado à história.

### Tecnologias

* HTML5
* CSS3
* JavaScript
* Figma

### Conceitos praticados

* Estruturação de páginas web
* Desenvolvimento de interfaces
* Organização de CSS
* Responsividade
* Interação com JavaScript
* Prototipação no Figma

🔗 **Demo:** https://douglasjhonyy.github.io/page-nexus/
